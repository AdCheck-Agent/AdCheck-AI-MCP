# 사회적 맥락 검수의 근거 사용과 판단 보류

## 사례에서 확인되는 범위

스타벅스 사례 보도는 행사일·상품명·함께 쓴 문구가 문제로 제기된 상황을 다룬다.
아이소이 사례 보도는 광고 집행 시점과 후에 논란·사과가 보도된 시점이 다를 수 있음을 보여준다.
근거: [전남일보](https://v.daum.net/v/20260518145300421),
[파이낸셜뉴스](https://busan.fnnews.com/news/202606301317329936).

## 프로젝트의 근거 사용 원칙

원문과 관련 사실을 확인한 뒤 역사·사회의 어떤 맥락과 연결되는지 설명한다.
신문의 비판 보도, 기업의 해명, 기관의 판단은 서로 다른 종류의 근거이다.
기업이 사과했다는 사실로 모든 의혹·의도·손해 규모까지 사실로 확장하지 않는다.
게시일·사건일·보도일·자료 확인일을 구분하고, 추정 날짜는 정확한 일자로 만들지 않는다.

## 판단 보류 조건

- 날짜·회사·제품·대상 고객·광고 이미지가 없으면 판단이 달라질 수 있는 경우
- 원문을 확보하지 못하고 짧은 검색 요약만 있는 경우
- 출처가 충돌하거나 정정·삭제·후속 해명을 확인해야 하는 경우
- 확인되지 않은 사례를 사실처럼 전제해야만 위험 판단이 가능한 경우

관련 사례가 검색됐다는 이유만으로 현재 광고가 같은 문제라고 판단하지 않는다.
검색 실패·미검색은 위험 부재의 근거가 아니다.
실제로 확보한 자료만 evidence로 반환하고 불확실성은 needs_review 판단에 전달한다.

## 적용 범위와 입력 한계

이번 자료는 텍스트 기반 사회·역사 검수의 일부 기준이다.
한일 과거사·식민지 상징·특정 참사의 세부 사실은 아직 별도 검증 문서를 갖추지 않았다.
그 영역을 이미 검증한 것처럼 통과시키지 말고 근거 보강 대상으로 처리한다.
게시 예정일·이미지·모델 나이 등을 현재 ReviewContext가 받지 않으므로,
Agent와 Backend가 필요한 추가 입력 계약을 정하기 전에는 없는 정보를 추정하지 않는다.
