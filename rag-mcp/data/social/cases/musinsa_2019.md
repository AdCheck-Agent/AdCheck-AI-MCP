# 무신사 2019년 양말 광고와 2026년 재사과 보도

## 보도에서 확인한 사실

MBN은 2026년 5월 20일 무신사가 2019년 7월 양말 광고에
책상을 탁 쳤더니 억하고 말라서라는 문구를 쓴 일에 재차 사과했다고 전했다.
출처: [MBN, 2026-05-20](https://v.daum.net/v/3Tvd1GOcI1).

## 시점과 맥락

양말 건조 성능을 설명하는 표현이 박종철 고문치사 사건 당시의 은폐 설명을 연상시킨다는 사례다.
광고 게시 시점인 2019년과 재사과 보도 시점인 2026년을 구분한다.

## 확인 범위와 사용 제한

기사에 실린 회사 입장과 광고 문구를 짧게 재서술한 것이다.
가해 의도나 교육·후원의 독립 검증 결과로 사용하지 않는다.
고문치사 사건 자체의 역사적 근거는 민주화운동기념사업회 자료를 별도로 사용한다.
사건 은폐 문구를 실제 사망 원인이나 가벼운 유행어로 서술하지 않는다.
