# 네네치킨 지사 SNS 고인 합성 이미지 논란

## 보도에서 확인한 사실

뉴스핌은 2015년 7월 2일 네네치킨 경기서부지사 페이스북에 전날 노무현 전 대통령의
합성 이미지가 게시됐고 회사가 사과했다고 보도했다.
출처: [뉴스핌, 2015-07-02](https://www.newspim.com/news/view/20150702000388).

## 프로젝트에서 비교할 맥락

고인의 이미지를 음식 홍보에 결합한 사례로, 밈·합성물의 출처와 대상의 존엄성을 함께 확인할 필요가 있다.
이는 본문에서 도출한 프로젝트의 검토 방향이다.

## 확인 범위와 사용 제한

고인을 닭다리 형태로 그렸다는 식으로 사용자가 제공한 설명을 그대로 복제하지 않는다.
회사·직원 전체의 특정 커뮤니티 소속, 조직적 의도, 확정된 법적 책임이나 브랜드 손실은 이 자료로 단정하지 않는다.
이미지 맥락이 중요한 사례이므로 텍스트만 받아 동일한 이미지가 있다고 판단하지 않는다.
